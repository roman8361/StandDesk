Техническое задание
Сервис учёта учеников для регулировки конторок
1. Описание проекта

Необходимо разработать простой веб-сервис для учителей, который позволяет вести учёт учеников в классах для дальнейшей настройки и распределения школьных конторок.

Конторка — это комплект из двух парт:

одна для работы стоя;
одна для работы сидя.

Во время урока ученики меняются местами: один стоит, другой сидит.

На первом этапе сервис нужен только для ввода и хранения данных учеников.

2. Типы пользователей
2.1. Учитель

Учитель может:

войти в систему;
создавать классы (например: 5Б);
указывать количество учеников;
заполнять карточки учеников;
редактировать и удалять своих учеников;
видеть только свои классы и данные.
2.2. Суперпользователь (админ)

Суперпользователь может:

войти в систему;
видеть всех учителей;
видеть все классы;
видеть всех учеников;
открывать любой класс;
редактировать и удалять любые записи.

12. Итоговая задача для Replit AI

Создай простой адаптивный веб-сервис для учителей для учёта учеников в школьных классах.

В системе должно быть 2 роли: учитель и администратор.

Учитель может создавать классы (например 5Б), указывать количество учеников и заполнять карточки учеников (ФИО, возраст, рост, зрение, вес).

Учитель видит только свои данные.
Администратор видит всех пользователей, все классы и всех учеников.

Нужно реализовать:

авторизацию
роли пользователей
создание классов
ввод учеников
просмотр и редактирование данных

Интерфейс должен быть адаптивным (работать на телефоне и компьютере) и выполнен в светлом современном образовательном стиле с карточками и простой навигацией.
